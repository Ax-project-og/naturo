# Contenu original — backup du site Simplébo

Copie du site https://www.isabelle-gayet.fr telle qu'en ligne le 24/10/2026, avant la refonte.
Ne pas modifier : c'est la référence des textes rédigés par Isabelle Gayet.

- `textes/` — texte de chaque page converti en Markdown (titres, listes, gras conservés ;
  en-tête, menu et pied de page retirés). Le title d'origine est en commentaire en tête de fichier.
- `html/` — HTML brut de chaque page (contient aussi les 3 commentaires de l'article détox),
  `sitemap.xml` et la feuille de style du thème (`dyn.css`).
- `images/` — toutes les images du site, en résolution d'origine, préfixées par leur identifiant
  Simplébo. Notables :
  - `2972503_isabelle-gayet.png` : logo Gaïaroma haute définition (3375×4500)
  - `logo_gaiaroma_black.png` : logo 600×600
  - `2972675_isabelle-gayet.jpeg` : portrait d'Isabelle (360×480)
  - `2950476_naturopathie-a-ferrieres-en-brie.jpeg` : photo d'un cabinet (probablement l'ancien, Ferrières)
  - les autres sont des visuels de banque d'images (Unsplash / bibliothèque Simplébo)
