        🏷️ Titles et meta descriptions optimisés

        Dans Simplébo → paramètres SEO de chaque page. Titles de 53 à 62 caractères, meta descriptions de 134 à 151 caractères. Aucune page n'a de meta description aujourd'hui.

        Articles de blog : reprendre le titre de l'article dans le title, sans le suffixe « | Blog », et écrire une meta description de 150 caractères qui résume le conseil principal.

        📋 Balisage structuré du cabinet

        Ce code décrit le cabinet à Google : nom, adresse, téléphone, tarifs, zone desservie. À placer dans l'en-tête de toutes les pages. Simplébo ne propose pas toujours l'ajout de code personnalisé : si l'option n'apparaît pas dans votre tableau de bord, demandez-le au support Simplébo.

        À compléter : ajoutez vos horaires (champ « openingHoursSpecification ») et l'URL d'une vraie photo du cabinet (champ « image ») avant de publier.
